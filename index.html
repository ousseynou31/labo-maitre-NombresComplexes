👤 Auteur & Mission

Auteur : [Ton Nom / Équipe]

Mission : Fournir un environnement interactif pour l'étude approfondie des nombres complexes, de l'algèbre polynomiale et des propriétés géométriques du plan complexe.

🧮 Analyse & Points

  • [Z] : Saisie manuelle d'un affixe $z = a + bi$.
  • [Arg] : Visualisation de l'argument $\theta = Arg(z)$.
  • [Mod] : Visualisation du module $|z|$.
  • [Solveur] : Résolution d'équations $P(z)=0$ (degré 1 à 5).
  • [Conj] : Génère automatiquement le conjugué $\bar{z}$.
  • [Opp] : Génère l'opposé $-z$ du point sélectionné.
  • [Inv] : Calcule l'inverse $1/z$ (si $z \neq 0$).
  • [Carré] : Calcule l'élévation au carré $z^2$.
  • [Racine] : Affiche les racines carrées complexes de $z$.
  • [Exp] : Calcule l'exponentielle complexe $e^z$.
  • [Log] : Calcule le logarithme complexe $\ln(z)$.

📐 Géométrie & Vue

  • [Segment] : Relie deux points pour créer un vecteur ou côté.
  • [Cercle] : Trace un cercle à partir d'un centre et d'un point.
  • [Moyen] : Calcule l'affixe du milieu d'un segment.
  • [Dist] : Affiche la distance entre deux points sélectionnés.
  • [Angle] : Mesure l'angle formé par trois points.
  • [Rotation] : Applique une rotation autour de l'origine.
  • [Palette] : Change la couleur des prochains éléments.
  • [🔍+] / [🔍-] : Ajuste le zoom du plan complexe.
  • [🏠 Centrer] : Recadre la vue sur l'origine $O(0,0)$.
  • [↩️ Retour] : Annule la dernière action (Historique).
  • [🗑️ Effacer] : Réinitialise complètement le laboratoire.
  • [❓ Aide] : Affiche ce guide utilisateur.
